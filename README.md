# Практическая работа №3: Ассемблер и интерпретатор УВМ (Вариант №13)

CLI-ассемблер и интерпретатор для учебной виртуальной машины (УВМ) с объединенной памятью команд и данных и языком ассемблера в формате YAML. Реализация выполнена на Python 3 (работает на стандартной библиотеке; при наличии `PyYAML` автоматически использует его).

## Спецификация УВМ и язык ассемблера

Программа задается YAML-файлом с корневым ключом `program`, содержащим список команд. Каждая команда — словарь с ключом `op` и именованными операндами. Пустые строки игнорируются, комментарии начинаются с `#`. Числовые значения допускаются в десятичном (`758`) и шестнадцатеричном (`0x2F6`) виде. Размер каждой команды фиксирован — **13 байт**, порядок байтов — **Little-Endian**.

| Команда | `A` (биты 0–6) | Размер | Синтаксис YAML (`op` и поля) | Поля и диапазоны | Семантика |
| :--- | :---: | :---: | :--- | :--- | :--- |
| Загрузка константы | `111` | 13 байт | `op: load_const`, `dest`, `value` | `B` (7–34): адрес `0..268435455`; `C` (35–48): константа `0..16383` | `mem[dest] = value` |
| Чтение из памяти | `17` | 13 байт | `op: read_mem`, `dest`, `src` | `B` (7–34): адрес `0..268435455`; `C` (35–62): адрес `0..268435455` | `mem[dest] = mem[src]` |
| Запись в память | `46` | 13 байт | `op: write_mem`, `src`, `dest` | `B` (7–34): адрес `0..268435455`; `C` (35–62): адрес `0..268435455` | `mem[dest] = mem[src]` |
| Унарный минус | `87` | 13 байт | `op: unary_minus`, `src_ptr`, `dest` | `B` (7–34): адрес-указатель `0..268435455`; `C` (35–62): адрес `0..268435455` | `mem[dest] = -mem[mem[src_ptr]]` |

### Пример программы (`tests/spec_test.yaml`)

```yaml
program:
  # A=111, B=758, C=112 -> 0x6F, 0x7B, 0x01, 0x00, 0x80, 0x03, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00
  - op: load_const
    dest: 758
    value: 112

  # A=17, B=390, C=965  -> 0x11, 0xC3, 0x00, 0x00, 0x28, 0x1E, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00
  - op: read_mem
    dest: 390
    src: 965

  # A=46, B=740, C=924  -> 0x2E, 0x72, 0x01, 0x00, 0xE0, 0x1C, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00
  - op: write_mem
    src: 740
    dest: 924

  # A=87, B=766, C=7    -> 0x57, 0x7F, 0x01, 0x00, 0x38, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00
  - op: unary_minus
    src_ptr: 766
    dest: 7
```

## Описание функций и настроек

### Модуль `src/main.py`

* `CommandSpec`, `Instruction` — структуры описания команд и внутреннего (промежуточного) представления (`field_a`, `field_b`, `field_c`).
* `parse_scalar()`, `parse_key_value()`, `append_yaml_line()`, `parse_simple_yaml()`, `load_yaml_data()` — разбор YAML-документа программы.
* `validate_field()`, `extract_operand()`, `parse_instruction()`, `translate_yaml()` — проверка наличия, типов и битовых границ операндов, трансляция команд в список объектов `Instruction`.
* `encode_instruction()`, `encode_program()` — битовая упаковка промежуточного представления в 13-байтовый машинный код (Little-Endian).
* `format_bytes()`, `write_binary()` — форматирование байтов в вид `0xXX, ...` и сохранение двоичного файла.
* `build_arg_parser()`, `main()` — обработка аргументов командной строки, вывод размера выходного файла в байтах и печать байтов в режиме тестирования.

### Параметры командной строки

* `input_path` — путь к исходному YAML-файлу с текстом программы.
* `output_path` — путь к двоичному файлу-результату.
* `--test` (`-t`) — режим тестирования (выводит байтовое представление каждой команды в формате `0xXX, ...`).

## Запуск и тестирование

Быстрая проверка через скрипт (Linux / Git Bash):

```bash
chmod +x run.sh
./run.sh
```

Запуск теста Этапа 2 (Windows PowerShell):

```powershell
.\tests\test_stage2.ps1
```

Ассемблер (Этапы 1–2):

```powershell
python src/main.py <input.yaml> <output.bin> [--test]
```

Интерпретатор (Этапы 3–4, планируется):

```powershell
python src/interpreter.py <program.bin> <dump.xml> <start:end>
```

* Выгружает указанный диапазон объединенной памяти УВМ в формате XML.
