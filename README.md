# Практическая работа №3: Ассемблер и интерпретатор УВМ (Вариант №13)

CLI-ассемблер и интерпретатор для учебной виртуальной машины (УВМ) с объединенной памятью команд и данных и языком ассемблера в формате YAML. Реализация выполнена на Python 3 (работает на стандартной библиотеке; при наличии `PyYAML` автоматически использует его).

## Спецификация УВМ и язык ассемблера

Программа задается YAML-файлом с корневым ключом `program`, содержащим список команд. Каждая команда — словарь с ключом `op` и именованными операндами. Пустые строки игнорируются, комментарии начинаются с `#`. Числовые значения допускаются в десятичном (`758`) и шестнадцатеричном (`0x2F6`) виде. Размер каждой команды фиксирован — **13 байт**, порядок байтов — **Little-Endian**. Память команд и память данных объединены в единое адресное пространство (`4096` ячеек): ассемблированная программа загружается начиная с адреса `0`, данные размещаются в свободных адресах той же памяти.

| Команда | `A` (биты 0–6) | Размер | Синтаксис YAML (`op` и поля) | Поля и диапазоны | Семантика |
| :--- | :---: | :---: | :--- | :--- | :--- |
| Загрузка константы | `111` | 13 байт | `op: load_const`, `dest`, `value` | `B` (7–34): адрес `0..268435455`; `C` (35–48): константа `0..16383` | `mem[dest] = value` |
| Чтение из памяти | `17` | 13 байт | `op: read_mem`, `dest`, `src` | `B` (7–34): адрес `0..268435455`; `C` (35–62): адрес `0..268435455` | `mem[dest] = mem[src]` |
| Запись в память | `46` | 13 байт | `op: write_mem`, `src`, `dest` | `B` (7–34): адрес `0..268435455`; `C` (35–62): адрес `0..268435455` | `mem[dest] = mem[src]` |
| Унарный минус | `87` | 13 байт | `op: unary_minus`, `src_ptr`, `dest` | `B` (7–34): адрес-указатель `0..268435455`; `C` (35–62): адрес `0..268435455` | `mem[dest] = -mem[mem[src_ptr]]` |

### Пример программы (`tests/spec_test.yaml`)

```yaml
program:

  - op: load_const
    dest: 758
    value: 112

  - op: read_mem
    dest: 390

  - op: write_mem
    src: 740

```

## Описание функций и настроек

### Модуль `src/main.py` (Ассемблер)

* `CommandSpec`, `Instruction` — структуры описания команд и внутреннего (промежуточного) представления (`field_a`, `field_b`, `field_c`).
* `parse_scalar()`, `parse_key_value()`, `append_yaml_line()`, `parse_simple_yaml()`, `load_yaml_data()` — разбор YAML-документа программы.
* `validate_field()`, `extract_operand()`, `parse_instruction()`, `translate_yaml()` — валидация операндов и трансляция YAML в список `Instruction`.
* `encode_instruction()`, `encode_program()` — битовая упаковка команд в 13-байтовый машинный код (Little-Endian).
* `format_bytes()`, `write_binary()` — форматирование байтов в вид `0xXX, ...` и запись бинарного файла.
* `build_arg_parser()`, `main()` — обработка CLI-аргументов и вывод размера файла / байтов.

### Модуль `src/interpreter.py` (Интерпретатор и АЛУ)

* `parse_memory_range()` — разбор и проверка диапазона адресов памяти формата `start:end` (включительно).
* `load_program_into_memory()` — загрузка 13-байтовых команд из бинарного файла в начало объединенной памяти УВМ.
* `decode_word()` — декодирование команды из объединенной памяти в промежуточное представление `Instruction`.
* `validate_address()` — проверка выхода адреса за границы объединенной памяти.
* `execute_unary_minus()` — выполнение операции АЛУ `унарный минус` (`mem[C] = -mem[mem[B]]`).
* `execute_instruction()` — диспетчеризация и выполнение всех команд УВМ (`A=111`, `A=17`, `A=46`, `A=87`).
* `run_program()` — основной цикл интерпретации.
* `save_memory_dump_xml()` — выгрузка указанного диапазона памяти в XML-файл.
* `build_arg_parser()`, `main()` — обработка аргументов командной строки интерпретатора.

### Параметры командной строки

Ассемблер:

```powershell
python src/main.py <input.yaml> <output.bin> [--test]
```

* `input.yaml` — путь к исходному YAML-файлу с текстом программы.
* `output.bin` — путь к двоичному файлу-результату.
* `--test` (`-t`) — вывод байтового представления команд в формате `0xXX, ...`.

Интерпретатор:

```powershell
python src/interpreter.py <program.bin> <dump.xml> <start:end>
```

* `program.bin` — путь к бинарному файлу с ассемблированной программой.
* `dump.xml` — путь к выходному XML-файлу дампа памяти.
* `start:end` — включительный диапазон адресов памяти для сохранения в дамп (например, `300:303`).

## Примеры использования

Ассемблирование и запуск программы проверки унарного минуса (`42` → `-42`, `0` → `0`, `1234` → `-1234`, `-42` → `42`):

```powershell
python src/main.py tests/unary_minus_test.yaml unary_minus.bin
python src/interpreter.py unary_minus.bin dump.xml 300:303
```

Содержимое `dump.xml`:

```xml
<?xml version='1.0' encoding='utf-8'?>
<memory>
  <cell address="300">-42</cell>
  <cell address="301">0</cell>
  <cell address="302">-1234</cell>
  <cell address="303">42</cell>
</memory>
```
